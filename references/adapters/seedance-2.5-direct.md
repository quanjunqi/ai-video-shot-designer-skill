# Seedance 2.5 直接模型 Prompt 契约

`prompt_contract=seedance-2.5-direct-v1`。本契约来自用户提供并确认的提示词结构，只证明项目可以生成和机械校验直接模型 Prompt；它不是官方 API 或平台能力声明。

## 支持边界

- 仅支持 `delivery_method=model`、`target_model=seedance-2.5`、`api_platform=null`。
- 不声明 API 字段、分辨率、帧率、素材数量上限、字符硬上限或任务轮询协议。
- 用户提供的结构将 `4-30 秒`作为自检口径。由于来源不是官方平台文档，校验器默认将它报告为项目契约错误，而不是“官方模型硬限制”；可用命令行参数覆盖。
- Prompt 使用中文结构和整数秒时间段。H3 六字段、`<Subject N>` 与 `ref_image_N` 不适用。

## 固定结构

有素材时字段顺序为：

```text
【全局声音与字幕约束】
【素材说明】
【一句话概述】
【全局视觉设定】
【详细情节】
【全局连续性与结尾约束】
```

用户确认不使用素材时，完全省略 `【素材说明】`，不要写空占位。首节默认写“不要BGM、不要字幕，只保留音效”，但用户明确要求 BGM 或字幕时以用户要求为准；对白不受默认禁令影响。

`【素材说明】` 按真实上传顺序使用 `@图片1`、`@图片2` 等连续句柄。每项同时说明“参考什么”和“不参考什么”。未上传素材不得出现；改变顺序后 Prompt 失效并重新派生。

每份可提交 Prompt 只对应一个生成单元，并在 Manifest 的 `artifacts.delivery_draft.unit_ids` 中只绑定该单元。多单元项目分别生成、校验和交付 Prompt。

`【一句话概述】` 包含人物、地点、核心事件或情绪变化、拍摄形式和预计总时长。拍摄形式由导演设计决定，不按时长档位决定。

`【全局视觉设定】` 固定包含全局风格、关键材质与受光表现、灯光基线。这里不写具体镜头动作或运镜。

## 多镜头

每段标题使用 `{开始}-{结束}秒｜镜头N`，连续覆盖完整时长。每镜字段顺序固定：

```text
画面动作概述
画面构图
机位
动作/表演
对白
声音
转场
```

每镜只有一个主视觉任务，但保留连续动作链。机位写清起始状态、跟随对象、触发变化和结束动势。除最后一镜外必须交代转场；切镜必须有信息、表演、空间或节奏职责，并继承位置、速度、方向、重心、视线、道具、摄影机侧位和声音。

## 单镜头一镜到底

`【详细情节】` 首先声明“全程单镜头、无剪辑、不中断、不跳轴”。时间段使用“路径节点”“阶段”或“节拍”，不得使用“镜头N”，也不得出现硬切、跳切、换机位或瞬移。每个节点继承上一节点的人物、道具、视线和摄影机方向；时间段只是连续摄影机路径节点。

## 剧本、空间与结尾

- 所有事件和对白回溯到 `EV/DLG/LOCK`；对白逐字保留说话人、字词和顺序。
- 详细情节使用连续整数秒时间段，覆盖完整单元，不重叠、不留空洞。
- 多人、道具与摄影机几何继承 scene map；情绪转译为可见、可表演事件。
- `【全局连续性与结尾约束】` 锁定人物、空间、道具、轴线、结束画面和必要防错项。
- v3 默认不使用故事板作为事实来源。只有用户明确选定且已确认的单镜构图参考，或旧项目保留的已确认故事板图，才可作为一个 `@图片N`；它只提供声明的构图用途，不覆盖剧本、空间、镜头或身份事实。带格框、编号、箭头和文字的旧图必须明确排除这些元素；不使用时完全省略相关说明。

## 校验

```bash
python3 scripts/validate_seedance_prompt.py draft.md
```

校验器只检查结构、字段顺序、素材句柄、拍摄形式、整数秒时间段和明显的模板冲突。剧本忠实、镜头必要性、空间可行性和表演质量仍由跨层校验及人工复核负责。
